# HR Analytics Dashboard

An interactive HR analytics report built with Microsoft Power BI. The dashboard is designed to help explore workforce data and make HR trends easier to understand through visual summaries.

## Dashboard overview

The report can be used to review HR indicators such as:

- Employee headcount and workforce composition
- Employee attrition and retention trends
- Demographic breakdowns, such as age, gender, department, or job role
- Employee satisfaction and other workforce-related measures, when available in the source data

The exact metrics, filters, and visuals depend on the data model and report pages in the Power BI file. No specific totals or findings are listed here because the underlying data values are not documented in this repository.

## Project file

- `HR-Analytics Dashboard.pbix` — Power BI report file.

## Open the dashboard

1. Download or clone this repository.
2. Open `HR-Analytics Dashboard.pbix` in Microsoft Power BI Desktop.
3. If Power BI prompts for a data source, configure the source required by the report. A separate data file is not included in this repository listing.

## Data note

Use the report's filters and visuals to inspect the available HR data. Confirm the data source, reporting period, and metric definitions before using dashboard figures for decisions. Handle employee data in accordance with your organization's privacy and access policies.
