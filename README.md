# HR Analytics Dashboard

An interactive Microsoft Power BI dashboard for analyzing workforce trends, employee performance, and HR-related metrics. This project is designed to help HR teams and business stakeholders explore patterns in headcount, attrition, retention, demographics, and employee experience.

## Overview

The dashboard provides a visual summary of core HR indicators, including:

- Employee headcount and workforce composition
- Attrition and retention trends
- Demographic breakdowns by age, gender, department, and job role
- Employee satisfaction and engagement indicators, when available in the source data
- Workforce insights that support operational and strategic HR decisions

The exact visuals, filters, and pages depend on the report structure and the data available in the Power BI file.

## Why this project?

This dashboard helps HR teams quickly identify workforce trends and answer common business questions such as:

- Is headcount increasing or declining over time?
- Which departments or job roles have higher attrition?
- Are there demographic patterns in workforce composition?
- How do employee satisfaction and engagement metrics vary across teams?

## Project files

- `HR-Analytics Dashboard.pbix` — Power BI report file

## Prerequisites

To open and use the dashboard, you will need:

- Microsoft Power BI Desktop
- Access to the data source used by the report
- A valid Power BI environment configured for the dataset

## How to open the dashboard

1. Download or clone this repository.
2. Open `HR-Analytics Dashboard.pbix` in Microsoft Power BI Desktop.
3. If the report prompts for a data source, connect to the appropriate source and configure credentials as needed.
4. Refresh the report if necessary, then explore the available filters and visuals.

## Data note

This repository does not include a separate source data file. The dashboard depends on the data model and data source used when the report was built.

Before making HR decisions based on this dashboard, confirm:

- the reporting period
- the data source and refresh status
- the definitions of each metric
- whether the data reflects the intended employee population

## Dashboard usage

Use the filters and visuals in the report to explore:

- workforce size and composition
- retention and attrition patterns
- employee distribution across departments or roles
- demographic trends
- satisfaction and other available workforce measures

## Limitations

- The dashboard is only as reliable as the underlying dataset.
- Metrics and page layouts may vary depending on the source data model.
- Some employee measures may require additional governance, validation, or source documentation.
- This project is intended for exploratory analysis and reporting support, not as a replacement for formal HR analytics governance.
